# CAMELS-Afr
CAMELS-Afr (Catchment Attributes and Meteorology for Large Sample Studies - Africa) is a multi-level catchment dataset developed by International Water Management Institute to support hydrological research, modelling, and data-driven studies across Africa.
The dataset provides basin-level attributes and hydro-meteorological time-series data derived from a range of satellite observations, reanalysis products, global datasets, and hydrological data sources.

The dataset includes information on location, soil, climate, geology, land cover, and hydrology, together with derived basin characteristics and temporal variables at multiple spatial levels. 
The processing workflow includes automated extraction of basin attributes, calculation of derived hydrological and physical characteristics, quality checking, and restructuring of the resulting data into standardised CSV files.

This repository contains the Python scripts used to process and generate the CAMELS-Africa dataset, including basin attribute extraction, derived attribute calculation, time-series processing, CSV restructuring, and preparation of the final datasets.
The code is provided to support reproducibility and facilitate future updates and extensions of the CAMELS-Africa dataset.
